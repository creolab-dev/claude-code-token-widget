# 要件定義書: Claude Code Token Widget

## 1. プロジェクト概要

### 1.1 目的
Claude Codeのトークン使用量・コストをリアルタイムで確認できるデスクトップウィジェットアプリを開発する。

### 1.2 背景
- Claude Codeにはトークン使用量を確認する手段（`/cost`コマンド、ステータスライン）があるが、CLI内でしか確認できない
- 生成中やコマンド実行中にトークン消費を俯瞰的に確認したいニーズがある
- Windows向けのClaude Codeモニタリングウィジェットは未開拓領域

### 1.3 対象ユーザー
- **プライマリ**: 自分自身（個人開発者、Claude Code日常利用者）
- **セカンダリ**: Claude Codeを日常的に使用する開発者（OSS公開後）

### 1.4 スコープ

#### MVP（v1.0）に含めるもの
- Claude Codeのトークン使用量リアルタイム表示
- デスクトップ常駐ウィジェット（always-on-top）
- システムトレイ対応
- Windows 11対応

#### MVP に含めないもの（将来対応）
- macOS / Linux対応
- クロスツール対応（Cursor, Copilot, ChatGPT）
- チーム/組織ダッシュボード
- コスト予測・予算アラート
- クラウド同期
- 課金機能

## 2. 機能要件

### 2.1 データ表示機能

#### FR-001: トークン使用量の表示
- 入力トークン数（total_input_tokens）を表示する
- 出力トークン数（total_output_tokens）を表示する
- キャッシュ読み取りトークン数（cache_read_input_tokens）を表示する
- キャッシュ作成トークン数（cache_creation_input_tokens）を表示する

#### FR-002: コンテキストウィンドウ使用率の表示
- 使用率（used_percentage）を数値とプログレスバーで表示する
- 使用率に応じて色を変化させる（例: 緑→黄→赤）

#### FR-003: コスト表示
- セッションコスト（total_cost_usd）をUSDで表示する
- JPY表示への切り替えが可能（固定レートまたは手動設定）

#### FR-004: セッション情報の表示
- セッション経過時間（total_duration_ms）を表示する
- API通信時間（total_api_duration_ms）を表示する
- セッションID（session_id）を表示する（省略形）

#### FR-005: データのリアルタイム更新
- データソースの更新を検知し、表示を自動更新する
- 更新間隔: データソースファイルの変更検知から1秒以内

### 2.2 ウィンドウ機能

#### FR-006: always-on-top（常に最前面表示）
- ウィジェットを常にデスクトップの最前面に表示する
- ON/OFF切り替えが可能

#### FR-007: ウィンドウのドラッグ移動
- ウィジェットをドラッグで任意の位置に移動できる
- ウィンドウ位置を記憶し、次回起動時に復元する

#### FR-008: フレームレスウィンドウ
- OSのウィンドウ枠（タイトルバー等）を非表示にする
- コンパクトなウィジェットらしい見た目にする

#### FR-009: ウィンドウサイズ
- デフォルトサイズ: 約300px × 200px（コンパクト）
- リサイズ不可（固定サイズ）

### 2.3 システムトレイ機能

#### FR-010: システムトレイアイコン
- タスクバーのシステムトレイにアイコンを常駐させる

#### FR-011: トレイメニュー
- 表示/非表示の切り替え
- always-on-topの切り替え
- アプリの終了

### 2.4 データソース連携

#### FR-012: ステータスラインデータの読み取り
- Claude Codeのステータスラインスクリプトが書き出すJSONファイルを読み取る
- 読み取り対象ファイル: `~/.claude/token-usage.json`

#### FR-013: ファイル変更監視
- データソースファイルの変更を自動検知する
- ファイルが存在しない場合は「未接続」状態を表示する
- ファイルが削除された場合は「未接続」状態に戻る

### 2.5 設定機能

#### FR-014: 通貨設定
- USD/JPYの切り替え
- JPYの場合、為替レートを手動入力可能

#### FR-015: 透過度設定
- ウィジェットの背景透過度を調整可能（0〜100%）

## 3. 非機能要件

### 3.1 パフォーマンス

#### NFR-001: メモリ使用量
- アイドル時のメモリ使用量: 40MB以下

#### NFR-002: CPU使用率
- アイドル時のCPU使用率: 1%以下
- データ更新時のCPU使用率: 5%以下（瞬間的）

#### NFR-003: 起動時間
- アプリ起動から表示まで: 2秒以内

#### NFR-004: データ更新遅延
- ファイル変更検知から画面反映まで: 1秒以内

### 3.2 インストール・配布

#### NFR-005: インストーラーサイズ
- 10MB以下

#### NFR-006: 依存関係
- WebView2: Windows 11にプリインストール済み（追加インストール不要）
- その他の外部ランタイム: 不要

#### NFR-007: インストール方式
- MSIまたはNSISインストーラー（Tauriが提供）
- ポータブル版（インストール不要のexe）も提供

### 3.3 対応環境

#### NFR-008: 対応OS
- Windows 11（必須）
- Windows 10（ベストエフォート）

#### NFR-009: ディスプレイ
- HiDPI / 高解像度ディスプレイ対応
- マルチモニター環境対応

### 3.4 セキュリティ

#### NFR-010: データの取り扱い
- トークン使用量データはローカルのみで処理する
- 外部サーバーへのデータ送信は行わない
- APIキー等の機密情報は扱わない

### 3.5 UI/UX

#### NFR-011: テーマ
- ダークテーマをデフォルトとする
- ライトテーマへの切り替えは将来対応

#### NFR-012: 視認性
- 小さいウィジェットでも数値が読みやすいフォントサイズ
- コンテキスト使用率は色で直感的に把握可能

## 4. データソース仕様

### 4.1 ステータスラインJSON書き出しスクリプト

Claude Codeのステータスライン機能を利用して、セッションデータをJSONファイルに書き出す。

#### 入力（stdin）: Claude Codeが提供するJSONデータ
```json
{
  "context_window": {
    "total_input_tokens": 15234,
    "total_output_tokens": 4521,
    "used_percentage": 8,
    "current_usage": {
      "input_tokens": 8500,
      "output_tokens": 1200,
      "cache_creation_input_tokens": 5000,
      "cache_read_input_tokens": 2000
    }
  },
  "cost": {
    "total_cost_usd": 0.01234,
    "total_duration_ms": 45000,
    "total_api_duration_ms": 2300
  },
  "session_id": "abc123..."
}
```

#### 出力先
- `~/.claude/token-usage.json`

#### スクリプト配置先
- `~/.claude/statusline.sh`（bash）

#### Claude Code設定
```json
{
  "statusline": {
    "command": "~/.claude/statusline.sh"
  }
}
```

### 4.2 データフロー
```
Claude Code セッション
  │
  │ (ステータスライン更新のたびに)
  ↓
statusline.sh (stdinからJSON受信 → ファイル書き出し)
  │
  ↓
~/.claude/token-usage.json (中間ファイル)
  │
  │ (notify crateでファイル変更検知)
  ↓
Tauri Rust Backend (JSONパース → フロントエンドへ送信)
  │
  │ (Tauri IPC event)
  ↓
Svelte Frontend (リアルタイム表示更新)
```

## 7. 制約事項

### 7.1 前提条件
- Claude Codeがインストールされ、利用可能であること
- Claude Codeのステータスライン機能が有効化されていること
- `~/.claude/statusline.sh` が配置・設定されていること

### 7.2 既知の制約
- ステータスラインデータはClaude Codeセッション中のみ更新される
- セッションが終了すると最終データのまま表示が固定される
- 複数セッション同時実行時、最後に書き込んだセッションのデータが表示される
  - 将来的にセッション別表示を検討

### 7.3 依存関係
- Claude Codeのステータスライン機能（JSON形式）が廃止・変更された場合、対応が必要
- Windows WebView2のバージョンアップによる影響の可能性

## 8. 用語集

| 用語 | 説明 |
|------|------|
| トークン | LLMが処理するテキストの最小単位。入力・出力それぞれにカウントされる |
| コンテキストウィンドウ | LLMが1回の会話で処理できるトークンの最大量 |
| ステータスライン | Claude Codeの画面下部に表示される情報バー。スクリプトでカスタマイズ可能 |
| always-on-top | ウィンドウを常に他のウィンドウより前面に表示する機能 |
| システムトレイ | Windowsタスクバー右側の通知領域。常駐アプリのアイコンが表示される |
| Tauri | Rust製の軽量デスクトップアプリフレームワーク |
| IPC | Inter-Process Communication。TauriにおけるRustとフロントエンド間の通信 |
